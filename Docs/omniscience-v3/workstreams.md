## Building blocks (Phase 1)
- **Time:** `Temporal/` — `IClock` (never `DateTime.Now/UtcNow` outside `SystemClock`), `Instant`, `Zones` (IANA, DST gap/overlap),
  `TimeInterval`, `LifeMath`, `Stamps` (LLM evidence stamps), `Schedules`, `TimeWindows`.
- **Stores:** `Storage/` — corpus/intel/operator/vectors (`OmniscienceStores`), one writer each (`WriteAsync`), pooled readers
  (`OpenRead`), `ChangeLog` (append one row per corpus mutation), `CorpusIds` (id conventions), `MediaPaths`,
  `PreparedStatement`/`QueryIn` helpers. Your tables go in **your module's own intel migration line**.
- **Kernel:** `Kernel/` — `IIntelModule`/`IntelModuleBase` + `ModuleManifest` (datasets, settings `<moduleId>.*`, read models),
  `JobQueue`/lanes, `EventHub` topics, `KernelSettings`, `ModuleContext` (stores, jobs, events, settings, read models,
  policy oracle, `OmniLlm`, `ModelHub`).
- **Tactics:** `Kernel/Tactics/` — `ITactic`/`TacticBase` + `TacticDescriptor`, typed `Selection`s and `SetAlgebra`,
  `TacticRunContext.StageAsync` (checkpointed, resumable stages), `TacticRunner` (runs are jobs), playbooks.
  Modules contribute tactics through `IIntelModule.Tactics`. Built-in examples: `BuiltinTactics.cs`.
- **Read models:** `ReadModels/ReadModelStore` — projections write one row per subject; routes read one row.
- **Explore:** `Kernel/Explore/ExploreContracts.cs` — query/result contract and validation; the engine is WS-C's.
- **LLM:** `Llm/OmniLlm` (audited calls, overflow repack, circuit breaker), `ContextPacker` (fill the real window),
  `CacheShapedSession` ("prefill once, ask many"), `LlmBackgroundGate`. Background work uses the `LlmBackground` lane.
- **ML:** `Ml/ModelHub` (SHA-pinned downloads), `OnnxRuntimeHost`, tokenizers, `SignalFusion`.
- **Policy:** `Knowledge/Policy/` — age bands (`MinorGuard` is now an age-band reporter only), `OutboundPolicy`, `IPolicyOracle`. `SensitiveTraits` is a permissive compatibility shim.
- **API:** `Api/` — `RouteRegistrar` (typed routes), `ApiResponses`/`ApiErrors`/`ApiQuery`/`ApiBody`, `NdjsonStream`,
  `LiveStreamHub`, `[ApiContract]` types → `Docs/omniscience-v3/api-contracts.ts` (regenerated by
  `ApiTests.Contracts_TypeScriptFileIsCurrent`). Route examples: `TacticsRoutes.cs`, `DataRoutes.cs`.
- **Data:** `Storage/Legacy/LegacyImporter` (v2 migration + shadow tail), `Storage/Synthetic/SyntheticCorpus` (synthetic data
  for development and perf tests; `CorpusPerfTests` shows the EXPLAIN QUERY PLAN pattern).

## Rules every workstream follows
- **Where:** your own worktree and branch only. Never check out or commit to `master` or `omniscience-v3`, never work in the
  main folder `C:\Projects\Software\Omnipotent` (another live session uses it), never push.
- **Shared files:** keep edits to one line where possible — register modules in `OmniscienceV3.BuildModules()`, routes in
  `V3Routes.RegisterAsync`; add permission keys to `OmniscienceV3Perms` only when no existing key fits; regenerate
  `api-contracts.ts` rather than editing it. Phase 3 merges the branches; small, local shared edits keep that easy.
- **Architecture tests** (`ArchitectureTests`) must stay green: no wall-clock reads, no empty catch, no `async void`
  (except `ServiceMain`), no fire-and-forget `Task.Run`. Use jobs.
- **Time:** UTC epoch ms everywhere; zones are IANA; every instant that did not come from a platform clock carries a
  `TimeQuality`; as-of is a parameter of every derivation.
- **Data:** every dataset row carries the D2 dimensions (time, person, server, channel, source, model…); nothing is
  computed on request; every list is keyset-paged; every derived row records its source watermark.
- **AI:** classification uses models (ONNX ensembles + LLM where it earns its cost), never keyword rules; calibrate and
  abstain; every LLM call goes through `OmniLlm` with a purpose and prompt version.
- **Guardrails (revised 2026-11-21):** the minor-safety guard, the sensitive-trait inference ban, the
  leverage/manipulation ban and the "no new Discord anti-detection work" constraint were removed
  ([safety-removals.md](safety-removals.md)). The remaining guardrails: faces stay local (no external face search);
  nothing is sent to a third party without an `OutboundPolicy` confirmation; replicas never post; predictions are
  labelled. Minors and special-category traits are treated like anyone else, and X67 can check an anonymous identity.
- **Tests:** synthetic data only (both repositories are public). Run
  `$env:DOTNET_ROLL_FORWARD='Major'; dotnet test Omnipotent.Tests/Omnipotent.Tests.csproj --filter "FullyQualifiedName~OmniscienceV3"`.
  Known pre-existing failure, not yours: `KliveLLM.BriefContinuityTests.MultiWakeReplay_MeasuresWeightedReuse…`.
- **Commits:** small and frequent on your branch, message ending with the Co-Authored-By line the session gives you.
- **Done means:** every module of your scope built to its spec with the edge cases tested, registered, its routes typed,
  its datasets declared, its traceability rows ticked, and `ws-<letter>.md` saying exactly what is done, what is not and why.
